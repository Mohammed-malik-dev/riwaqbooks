# رِواق — متجر كتب عربي

واجهة متجر كتب عربية متجاوبة مستوحاة من تخطيط مواقع التجارة الإلكترونية، مبنية باستخدام HTML وCSS وJavaScript فقط دون باك إند.

## تشغيل المشروع
1. فك ضغط الملف.
2. افتح `index.html` في المتصفح.
3. يلزم الاتصال بالإنترنت لتحميل الخطوط وصور أغلفة الكتب من Unsplash.

## المزايا
- واجهة عربية RTL متجاوبة مع الهاتف والكمبيوتر.
- بحث عن الكتب بالعنوان أو المؤلف أو التصنيف.
- تصنيفات كتب قابلة للتصفية.
- إضافة للسلة وتعديل الكمية والحذف.
- قائمة مفضلة محفوظة في `localStorage`.
- حفظ محتويات السلة عند إعادة تحميل الصفحة.
- نموذج اشتراك تجريبي للنشرة البريدية.

## ملاحظات
هذا نموذج Frontend تجريبي. الأسعار والكتب أمثلة، وأزرار الدفع والاشتراك لا تنفذ معاملات فعلية. لتحويله إلى متجر حقيقي ستحتاج إلى API/Backend وقاعدة بيانات وربط بوابة دفع. صور الأغلفة المستخدمة صور توضيحية من Unsplash ويمكن استبدالها بأغلفة الكتب الفعلية.
